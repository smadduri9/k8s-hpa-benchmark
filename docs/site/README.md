# Portfolio site maintenance

The Pages home is a static case study: [generated HTML](../index.html), an
[authored template](index.template.html), [local CSS](../assets/css/site.css), and
the six existing SVG evidence figures. There is no JavaScript, remote font,
analytics, or runtime dependency. GitHub Pages can serve the committed HTML
directly from `docs/`; Jekyll excludes this template directory. Existing
methodology and archive documents remain available.

## Generate and check

Run from the repository root with the existing Python 3.14 virtual environment:

```bash
".venv/bin/python" scripts/generate_portfolio_site.py
".venv/bin/python" scripts/generate_portfolio_site.py --check
".venv/bin/python" scripts/check_portfolio_site.py
".venv/bin/python" -m unittest discover -s tests -p test_portfolio_site.py
```

The generator uses only the standard library and performs no network requests.
It reads [headline.json](../../artifacts/v1.1/summary/headline.json), validates
required numeric fields, derives workload peak ranges and sample counts, and
HTML-escapes template substitutions. Formatting rounds for display only; ratios
come directly from canonical ratios of unrounded medians. Missing, nonfinite,
negative, or malformed required data fails generation; nothing is backfilled.
`--check` compares in memory and never rewrites a stale page.

Edit narrative prose and layout in the template, not the generated home. Numeric
experiment headlines must use `{{ field.path|format }}` tokens. Declared settings,
the clearly withdrawn historical claim, and attributed dataset context are
authored facts rather than new measurements. Package size is calculated separately
from manifest byte counts plus the manifest and checksum files themselves. The
footer DOI identifies only the existing v1.0.0 archive. Existing SVGs remain generated by
the [publication figure pipeline](../../scripts/generate_public_figures.py).
Do not edit the evidence package or regenerate it to repair a website failure.

The existing [publication text command](../../scripts/generate_publication_text.py)
also invokes this generator, so its three-document check continues to cover
README, RESULTS, and Pages. CI runs generation freshness, structural/link checks,
and regression/rejection tests in addition to the existing publication and
documentation/privacy checks.

## Links and accessibility

Local image and stylesheet URLs are relative to the Pages home, so the repository
subpath works without JavaScript. Repository documents use absolute GitHub
`main` URLs. The offline checker resolves those URLs against public files in the
checkout, including Markdown anchors; external availability is a separate
network check. The new content becomes available at those URLs after a later
authorized publication of this branch. Site work itself does not push or deploy.

Figures retain their original white backgrounds in dark mode, preserving the
published evidence colors. Each has descriptive alternative text, adjacent text
or a table, and a full-size SVG link for small screens. Native `details` elements
provide keyboard-operable technical notes. Navigation wraps on mobile; no menu
script is needed. Focus states, semantic landmarks, a skip link, and reduced
motion styles are explicit.

## Visual verification

Serve `docs/` with a local HTTP server and inspect at 1440, 768, and 390 pixels,
in light and dark preference. Check the hero, metric reflow, all figures, footer,
anchor offsets, keyboard focus, technical disclosures, and page overflow. Open
full-size figures on mobile to inspect their small labels. Also inspect enlarged
text. Browser tooling and screenshots are local QA aids, not deployed dependencies
or committed site assets.

Scientific limitations remain visible on the page: fixed arm order, small and
unequal metric samples, unproven hardware attribution, only one calibration sweep,
omitted Prometheus evidence, and no usable published cold-start distribution.

## Phase 3 inspection record

Local Chromium inspection covered 1440px desktop, 768px tablet, and 390px mobile,
each in light and dark mode. All six figures loaded; page width matched viewport
width. The hero, result strip, figure sections, disclosures, provenance, evidence
commands, and footer were visually reviewed. Anchor navigation cleared the sticky
header; on mobile the header scrolls normally. The skip link moved keyboard focus
to the main content, and native disclosures opened with Enter. At 200% text size
on mobile, content wrapped without horizontal page scrolling.

An axe-core 4.10.3 WCAG A/AA scan reported no violations at all six combinations.
Its manual-review flags were arrow-glyph contrast; the actual foreground/background
pairs were checked separately and exceeded 4.5:1 in both themes. This is a scoped
accessibility check, not a claim of exhaustive assistive-technology certification.
The QA browser and scanner were temporary local tools, not site dependencies.
Screenshots remain outside the repository.

All local assets, section anchors, and checkout-mapped GitHub document links
passed. A read-only network check of 25 distinct outbound URLs returned HTTP 200
for 12 and HTTP 404 for 13. Every 404 targets new evidence or documentation
present in this branch but absent from public `main`; those links require the
later publication of the branch. The existing release, DOI, and trace-source
links resolved. No push or deployment was performed as part of this inspection.
